# Agent Note: 桌面端主模型设置

Status: implemented

[English](2026-08-29-desktop-primary-model-settings.md) | 中文

## 问题

Desktop 产品需要一份控制对话所用 ACP 运行时的 OpenAI 兼容模型配置。让 Renderer 持有明文凭据，或在 UI 中维护第二套模型客户端，都会暴露密钥，并绕过运行时负责的会话、工具、审批和持久化行为。

## 决策

Desktop 模型设置管理有名称的配置、默认配置、独立子模型端点、上下文与输出覆盖值，以及接口声明的思考选项。Electron 主进程校验端点，使用 `safeStorage` 加密密钥，并原子写入仅所有者可访问的 `model-profiles.json`。仅当配置列表不存在时导入旧 `primary-model.json`；旧容量缺失时把既有 32K 上下文和 8K 输出默认值保留为显式覆盖。不移动应用数据或其他产品的配置。preload 返回脱敏状态。

保存时对每个变化的端点进行有上限的函数工具文字请求验收，再检测可选图片输入。显式重新检测刷新主模型与子模型能力。留空密钥仅可在规范化 URL 和协议相同的情况下复用；编辑、检测和显式复用路径都遵守该限制。手动容量优先于接口元数据和模型、协议、官方 URL 完全匹配的 catalog 值。未知上下文容量要求明确填写。除非从已声明能力中选择覆盖值，通用网关继续使用服务端思考默认值。

[配置管理](../../../../apps/desktop/src/models/main/profiles.ts)负责串行修改和有上限的模型目录检测。Renderer 在发送前提供配置选择，在配置编辑器提供目录检测。目录成员不证明推理权限；保存不同模型仍需验收。独立子模型设置为普通子 Agent、fork 和 workflow 提供路由，不改变工具或企业授权。

[Runtime 池](../../../../apps/desktop/src/runtime/main/pool.ts)为活动请求保留不可变模型版本，并把取消发送到实际子进程。准备会话会固定该版本，直到发送或关闭；空会话跨版本时重新建立身份并保留草稿附件，不加载不存在的日志。持久会话通过企业 supervisor 恢复并保留显示引用。过时空闲版本终止。身份和工具变化在新准入前撤销全部版本；旧启动或完成不能向新身份发布状态。每个 supervisor 拥有凭证到期与续期；已发送失败的操作绝不自动重试。

本地逐请求诊断通过名为 `harnessDiagnostics` 的可选 ACP 元数据记录有限证据。凭据字段、lease 标识、Cookie 和常见凭据文本赋值在传输前与落盘前脱敏。打开消息日志检查当前企业会话权限。日志是临时诊断证据，不是持久对话或 Kernel 审计记录。专门 scan/change/audit 工具复用已有委派，不替换父 Agent 的完成策略；允许 Bash 不等于强制只读执行。

## 考虑过的替代方案

**从 Renderer 直接调用模型。** 这会简化表单提交，但会把凭据交给浏览器代码，并产生一套不包含运行时审批、工具和持久会话的并行对话实现。

**把 API Key 保存到 JSON 设置文件。** 这种方式更便于迁移，但会留下可复用的明文凭据。Electron `safeStorage` 使用操作系统保护存储，使配置文件不包含敏感明文。

**无条件替换共享 ACP 配置。** 这会改变 CLI、回放和快照行为。Desktop 专用环境开关把 provider 选择限制在打包应用托管的运行时内。

**探测每一种推理强度和上下文大小。** 重复付费请求仍无法可靠证明上下文上限，还可能在保存时触发限流。内置 catalog 为已知模型提供准确的 effort 数据；未知模型省略 effort 参数，端点元数据只有明确公布时才采用。

企业会话归属登记串行执行完整落盘事务，并仅在原子重命名成功后发布权威内存映射。写入失败不授予会话权限。退出登录后不能加载企业所属会话或打开其日志；归属文件无效时拒绝访问，不把企业历史当成本地历史开放。

## 后果

- 默认配置控制后续准备的请求；已准入请求保留原模型。
- 基线验收失败时，原有加密设置与正在运行的 Runtime 保持不变。
- 只有真实请求成功后才启用可选图片输入；仅文字模型仍可开启 Computer Use，但不能检查截图。
- 现有版本 1 和版本 2 设置会迁移为未验证的仅文字记录，并在下次保存时完成验收。
- Renderer 可以判断密钥是否存在，但不能读取密钥。
- 活动请求期间多个模型版本可并存；身份变化回收全部版本。端点验收失败保留原配置，子进程启动失败则明确展示，并需选择或修正配置。
- 容量发现仍是提示性信息，因为标准 OpenAI 模型列表响应没有定义模态、effort 或上下文字段。
