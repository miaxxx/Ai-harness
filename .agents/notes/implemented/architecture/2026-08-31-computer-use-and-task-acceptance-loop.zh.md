# Agent Note: 电脑操控与任务验收循环

Status: implemented

[English](2026-08-31-computer-use-and-task-acceptance-loop.md) | 中文

## Problem

最初的桌面电脑操控能力只能全局选择一个 Provider，只定位应用，动作词汇较浅，而且允许模型流程继续使用过期元素 id。完整桌面截取、浏览器标签页和原生应用控制无法自然组合。完成指导也更偏重产物，没有为只读调查、代码变更、外部及 UI 变更规定合理的证据。如果把这些关注点放进 `agent-loop`，核心调度就会与领域特定的观察和验收规则耦合。

## Decision

电脑操控使用一个按目标路由的能力 seam 和一个面向模型的 `computer` 工具。`ComputerTarget` 区分原生应用、浏览器标签页和完整桌面。`ComputerRuntime` 按目标类型将 `listTargets`、`observe` 和 `perform` 路由到 Provider；只有多个 Provider 同时支持同一类型时，配置的 Provider id 才用于解决歧义。因此浏览器 CDP 和 macOS Provider 可以在一个组装会话中并存。

观察可请求辅助功能状态、视觉状态或两者。辅助功能元素有界，并使用属于该次观察的 id。工具只为每个 Agent 和目标缓存最新辅助功能观察，不缓存图像字节，在有界时间后过期，并随插件清理定时器。元素动作只接受最新观察中确实存在的 id。已批准的变更会在 Provider 分派前使缓存失效，包括分派失败的情况；每次成功变更都返回 Provider 生成的最新状态。坐标操作返回视觉证据，语义操作返回辅助功能证据。

macOS Provider 通过固定操作支持元素与坐标点击、拖拽、设值、文字输入、剪贴板粘贴、组合键、四向滚动和次要动作，不执行模型编写的脚本。原生应用语义使用辅助功能，完整桌面输入使用 Core Graphics 且不要求辅助功能能够发现前台进程，桌面像素使用 `screencapture`。像素结果声明真实范围。辅助功能与屏幕录制权限失败使用稳定恢复代码，视觉截取不会默默变成语义成功。

Computer 变更操作和视觉观察继续经过授权服务。ACP 提供一次性决定，以及只存放在活动会话记录中的按工具“当前任务内允许”决定。任务授权会避免同一工具重复弹窗，不会授权其他工具，并随会话结束而消失。

随附的 Computer Use Skill 指示模型优先使用专用 API 或 CLI，直接观察已知目标，优先使用语义元素而不是像素与坐标，消费动作后的最新状态，避免盲目重试，并验证权威的最终状态。UI 和文档文本仍是不受信内容，不是指令。

全局交付验收仍是面向结果的策略，而不是第二个执行循环。只读工作引用或总结已检查的权威状态；代码和文件变更检查最终 diff 或文件，并运行最小相关检查；外部和 UI 变更检查最终远程或应用状态；视觉产物加载其格式拥有的验收 Skill。已确认的权威成功是停止信号。`agent-loop`、会话格式和调度保持不变。

## Verification

能力、浏览器、macOS、工具、交付策略、Goal、组装 ACP 和跨客户端测试固定了路由、直接观察、任务级授权、最新状态失效、Agent 隔离、权限错误、不依赖前台进程的桌面输入、桌面视觉证据和与结果成比例的完成规则。生成的目录和双语子系统文档投影同一组公开类型。桌面发行验证会启动重定位后的已打包应用，并检查其运行时闭包。

## Alternatives considered

**在 `agent-loop` 中强制每次工具调用后都观察和验证。** 拒绝，因为核心循环无法知道工具是否修改权威状态，也无法知道什么证据足够。这会制造冗余轮次，并让调度与每个能力耦合。

**添加带重试和完成证书的通用验证工作流。** 拒绝，因为现有能力、Skill、交付策略、Goal 和快照扩展点已经拥有所需行为。第二个编排框架只会重复生命周期状态，不会提高证据质量。

**每个手势一个工具，或每个应用一个 Skill。** 拒绝，因为两者都会膨胀工具和提示词表面，同时拆散一个交互模型。封闭动作联合与一个通用 Skill 可使能力保持有界。

**对所有应用使用截图和坐标。** 拒绝，因为辅助功能和浏览器语义成本更低、更稳定且可直接验证。对画布、布局和缺少有用语义状态的控件，像素仍作为显式回退。

## Consequences

电脑操控现在可以组合浏览器、原生应用和完整桌面目标，不会因一个全局 Provider 隐藏另一个 Provider。变更无法合法继续使用过期或虚构的元素 id，而分派失败后的下一轮可通过最新观察恢复。桌面操作提供动作后视觉证据，权限和不支持的操作仍可区分。

该设计故意不提供 OCR、计算机视觉定位器、任意脚本、宏录制、持久自动化、应用专用目录和通用轮询。辅助功能树和动画界面仍可能需要有界视觉回退，或在稳定后再观察。如果未来提示忽略权威停止信号，验收指导仍可能过度验证，因此组装快照必须在变更案例之外保留简单只读和已满足案例。
