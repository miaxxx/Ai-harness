# Agent Note：Desktop Next 业务承载

Status: implemented

[English](2026-10-01-desktop-next-business-host.md) | 中文

## 问题

Builder 发布的业务页面已由 OBIS Next Workspace 使用 React 渲染。另建 Desktop 生产渲染器会重复维护表单、权限和导航行为。

## 决策

Desktop 在 Mona/Harness 对话窗口右侧的沙箱 WebContentsView 中加载配置的 OBIS Next 根地址。可选 sidebar.navigation 插槽把业务入口放在原有工作区和会话浏览器上方；切回聊天保留已挂载的对话。固定入口包括应用、公共空间、资料库和 Builder。远程视图没有原生预加载脚本，拒绝权限请求、新窗口和跨来源跳转。原生模块链接在打开 Next 路由前验证发送方、作用域和 Kernel 页面权限。凭证不进入路由参数。

Desktop 后台从已认证人员源会话派生不透明 Web 会话，并写入 Next HttpOnly Cookie。仅 BFF 能将 Cookie 换取委托 API 凭证。入口切换检查原生凭证是否就绪，并在有效期内复用关联 Cookie。退出和租户切换清除 Cookie；跳转登录页隐藏业务视图并提示业务登录，不重载对话。退出后才完成的凭证签发不能重新打开业务视图。DOM 渲染器保留给原生预览和 Harness 启动浮层，其组件注册由 [Desktop 共用 UI Runtime 注册表](../feature/2026-09-30-desktop-shared-ui-runtime-registry.zh.md)负责。

原生 AI 读取由后台在同一服务端身份和作用域下消费需人工确认的 Workspace 票据。ACP Host 从凭证提供器读取委托访问凭证，挂载 OBIS 工具并创建关联来源会话的 AgentRun。签发期间作用域变化会拒绝启动。普通 AI 会话属于工作区，不隐式选择 Module。事件读取有时间上限，租约仅在 Host 请求头中使用，返回前关闭 SSE。

业务选择复用输入框引用编码和悬停子菜单。非机密 JSON 选择记录在用户消息中，工具适配器恢复后即可重建选择，无需读取渲染器状态。每个所选 Module 版本独立管理 Run 缓存键，附着时保留原 Harness Session 身份。Kernel 创建绑定 Run 前检查发布状态与授权。配置的引用自主级别允许需人工确认的操作提议，普通对话保持只读；渲染器选择不授予执行权限。

## 考虑过的替代方案

**另打包生产业务渲染器。** 页面变更需要同时发布两个业务客户端，并重复维护服务端操作适配器。

**将原生预加载脚本暴露给远程页面。** 业务页面不应取得本地文件系统或凭证 API。

**把 Bearer 写入业务 URL。** URL 会进入浏览历史、来源信息和服务日志。

## 影响

原生监督器单独记录委托到期时间。发送前对已到期的空闲 Runtime 续期，并恢复已授权会话；回复仍在运行时不替换 Runtime，服务端拒绝后不重试操作。来源会话撤销即使发生在委托到期前，也由服务端拒绝后续请求。

工具适配器单独处理 Host 管理的能力租约到期，通过同一个 Run、Session 和安装重新附着；并发续租共享请求，过期的续租结果在发送业务操作前被拒绝。外部配置的租约不被替换。

Host 恢复会话时，用回放帧包围按顺序交付的已授权 ACP 消息。渲染器替换历史显示，保留待发送实时消息的显示文本。最终消息块与可变缓冲分离，快照冻结不会阻断后续流式追加。 后续请求期间，历史回复保持最终状态；流式显示仅适用于最新用户消息之后的回复。

`DSH_DESKTOP_BUSINESS_WEB_URL` 必须是 HTTPS 根地址。`DSH_DESKTOP_USER_DATA` 指定独立的验收数据目录。业务来源不可用时页面加载失败。公共空间目前展示有权访问的应用，不提供文档协作。

导航版本同时覆盖页面授权与加载，因此被后续选择取代的请求不会替换或隐藏当前视图。目录刷新与导航准入独立。输入框候选复用已验证的展示元数据并合并后台刷新；每次页面读取与工具执行仍由服务端决定权限。子菜单根据悬停行的位置定位，并限制在视口内。

尚未发送消息的空会话没有持久日志。发送准入在凭证续期后重建所属空会话，并仅发送一次已序列化的输入；有日志的会话正常恢复。

## 测试

`apps/desktop/tests/business-window.spec.ts` 验证无效来源、隔离会话、无预加载脚本、跨来源拒绝、作用域 URL、HttpOnly Cookie 和退出期间签发竞态。原生启动、账号联动、Next 页面及三端对照须使用单独的运行证据验收。
