# Web research

Turn the request into a small set of distinct research questions. Search with focused queries, prefer primary and authoritative sources, and compare more than one source when a claim is disputed or consequential.

Separate sourced facts from inference. Track publication dates and the date an event happened when recency matters. Cite the direct source URL near each supported claim; do not cite a search-results page. If only search snippets are available, say so and avoid claiming details the snippet does not establish.

End with the answer the user can act on, followed by concise caveats or unresolved gaps. Do not expand the research scope merely because more material exists.
