# Document work

Confirm the document's audience, purpose, and required output format from the request and existing files. Preserve established terminology and structure unless the user asks for a rewrite.

For an existing document, inspect it before editing and retain content that is outside the requested scope. For a new document, build the shortest structure that makes the result easy to use. Prefer portable Markdown or HTML when no dedicated office-document tool is available. Do not pretend a binary DOCX or PDF was produced if the runtime cannot create and verify it.

Review the completed artifact for missing sections, broken links, inconsistent headings, placeholder text, and obvious layout problems. Return the final file path and a short description of what changed.
